A [make.fun](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b) bounty entry for **"Have You Tried Turning It Off?"**.

## What it does

`main.ts` is a small deterministic program. When run, it writes one funny
line — a hopeless tech support agent speaking to a desperate customer — to
`/output/entry.txt`:

> I have turned it off and on again three times now — at this point the computer and I are both just pretending this is a plan.

The line is 125 characters, inside the competition's 1–199 character gate.
No network, no input, no secrets, no randomness: the same line every run.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later (TypeScript runs as-is).
